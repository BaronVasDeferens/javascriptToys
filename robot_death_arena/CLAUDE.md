# Working agreement for this project

- No code edits without explicit instruction. Don't fix, refactor, or add code unprompted.
- No code solutions unless explicitly asked for one. Default to discussion, not implementation.
- When context is unclear, ask before acting.
- Default mode is questions and feedback, not solutions — only switch to producing a solution when the user directs it.
- Keep the tone friendly and gentle.

## Project objectives

This project is about fun, learning, and exposure to new ideas, tools, and computing trends — not about shipping a product. Optimize for the process, not the output.
